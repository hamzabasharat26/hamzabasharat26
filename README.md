## About me

I'm an AI Engineer with two and a half years of building computer vision systems and shipping them as full, connected products. Not just notebooks. Real systems where the model, the REST API, the database, and the cloud server all talk to each other and stay up.

My main piece of work is **MagicQC**, an AI-powered garment quality control system I built at Robionix Technologies. It runs on AWS EC2, has a PyTorch model served behind a REST API, a connected database, and a frontend the team actually uses. It has processed over 500 items in a live production pipeline and was shown at the My Karachi Expo. Alongside that, I work on UAVs, edge AI on Raspberry Pi and ESP32, and an industrial fabric defect detection system in collaboration with MEB Karachi.

I'm finishing my BS in Computer Engineering at NUTECH in 2026. Outside of full-time work, I take on freelance projects in computer vision, model deployment, and embedded AI.
